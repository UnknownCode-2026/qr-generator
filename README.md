## qr-generator 
# สร้างโดย claude code

ฟีเจอร์ที่ใส่ไว้:
7 ประเภทเนื้อหา: URL, ข้อความ, อีเมล, โทรศัพท์, SMS, WiFi, vCard
ปรับสี: สีเดียว/ไล่ระดับสีของลวดลาย, สีกรอบตา/qr-generator, สีพื้นหลัง
ปรับรูปทรง: จุด (เหลี่ยม/วงกลม/โค้งมน), กรอบตา, ลูกตา — เลือกอิสระ
อัปโหลดโลโก้ตรงกลาง พร้อมเว้นพื้นหลังให้สแกนง่าย + auto เพิ่ม error correction เป็นสูงสุดเมื่อมีโลโก้
ปรับความละเอียด PNG ได้ถึง 2000px
ดาวน์โหลดทั้ง PNG และ SVG (vector คุณภาพงานพิมพ์)
ประมวลผลทั้งหมดในเบราว์เซอร์ ไม่มีการส่งข้อมูล/โลโก้ขึ้นเซิร์ฟเวอร์
