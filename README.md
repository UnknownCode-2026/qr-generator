# 🚀 เกมบอล QR Studio Pro

โปรเจกต์เว็บแอปพลิเคชันสำหรับสร้าง QR Code สไตล์มืออาชีพที่ออกแบบมาเพื่อธุรกิจคาเฟ่ ร้านอาหาร (เช่น ร้านเกมบอล) และการใช้งานทั่วไป มาพร้อมกับอินเทอร์เฟซที่ทันสมัย ทำงานเสร็จสมบูรณ์ภายในเบราว์เซอร์ (Client-side) 100% ปลอดภัยและรวดเร็ว

---

## ✨ ฟีเจอร์เด่น (Features)

*   **🎨 ดีไซน์ทันสมัย (Modern UI):** ออกแบบด้วยสไตล์ Dark Mode ผสมผสาน Glassmorphism และ Neon Glow สวยงามน่าใช้
*   **⚙️ จัดการง่ายด้วย Config (Centralized Configuration):** แยกไฟล์ `config.js` เพื่อให้เจ้าของร้านเปลี่ยนชื่อเว็บ, ข้อความ Footer, และตั้งค่า WiFi เริ่มต้นของร้านได้ง่ายๆ โดยไม่ต้องยุ่งกับโค้ดหลัก
*   **📱 รองรับข้อมูลหลากหลายประเภท (Multi-format Support):**
    *   ลิงก์เว็บไซต์ (URL)
    *   ข้อความทั่วไป (Text)
    *   เครือข่าย Wi-Fi (พร้อมรหัสผ่านสำหรับแจกลูกค้า)
    *   เบอร์โทรศัพท์ (Phone)
    *   ข้อความ SMS
    *   นามบัตรอิเล็กทรอนิกส์ (vCard)
*   **🌈 ปรับแต่งสีสันลวดลาย (Customization):**
    *   รองรับทั้งสีทึบ (Solid) และสีไล่ระดับ (Gradient)
    *   แยกสีปรับแต่งได้ทั้ง สีพื้นหลัง, ลวดลาย, กรอบมุม (Eye Frame) และจุดกลางมุม (Eye Ball)
*   **💠 ปรับรูปทรงได้อิสระ (Shape Styling):** เปลี่ยนรูปทรงของจุด QR Code และกรอบตาได้ (สี่เหลี่ยม, วงกลม, ขอบมน)
*   **🖼️ แทรกโลโก้ตรงกลาง (Logo Integration):** อัปโหลดภาพโลโก้ร้านค้าพร้อมฟังก์ชันเว้นกรอบพื้นหลัง (Knockout) เพื่อให้สแกนได้แม่นยำขึ้น
*   **⚡ พรีวิวแบบเรียลไทม์ (Live Preview):** แสดงผลลัพธ์ของ QR Code ทันทีที่พิมพ์ข้อมูลหรือปรับเปลี่ยนการตั้งค่า
*   **📥 ส่งออกไฟล์ความละเอียดสูง (High-Resolution Export):** ปรับความละเอียดก่อนดาวน์โหลดไฟล์ PNG ได้สูงสุดถึง 2400x2400 px
